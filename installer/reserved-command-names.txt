# Reserved command names — shipped Rig commands and skills must never use these.
#
# Why: Claude Code lets a project or personal skill/command with the same name
# replace a built-in command (its aliases still reach the built-in), and it
# refuses to load custom skills named ship, ship-local or steward. Codex lists
# same-named skills side by side. See issue #714 (and #121 for the first case).
#
# Sources and review:
#   claude  https://code.claude.com/docs/en/commands ("All commands" table,
#           including bundled skills and every alias) and
#           https://code.claude.com/docs/en/slash-commands ("Resolve skills
#           that share a name"). Reviewed 2026-11-24 against Claude Code 2.1.331.
#   codex   codex-rs/tui/src/slash_command.rs at tag rust-v0.172.0
#           (https://github.com/openai/codex). Every SlashCommand variant in
#           kebab-case plus each strum to_string/serialize alias. This is a
#           deliberate superset: a variant renamed by to_string keeps its
#           kebab-case name here too. Reviewed 2026-11-24.
#
# Refresh both lists during The Rig's upstream release audit. Format: one
# "provider name" pair per line; blank lines and # comments are ignored.
